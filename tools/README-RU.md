## auth-center

Единый центр аутентификации — отправная точка экосистемы.

Мне всегда было скучно делать аутентификацию с нуля для каждого нового
приложения. А если появлялся новый провайдер, его приходилось добавлять в
каждое приложение по отдельности — это вдвойне уныло. Так пришла идея сделать
один центр для всех.

## Что внутри

- **Подключаемые провайдеры** — вынесены отдельно, поэтому новый подключается без боли
- **Доверие между приложениями** — личность подтверждают не только люди, но и приложения, когда общаются между собой: так контур остаётся защищённым
- **Для любого приложения** — подключить можно что угодно, не обязательно из моей экосистемы
