## auth-center

A single authentication hub — the starting point of the ecosystem.

Building authentication from scratch for every new app always bored me. And
whenever a new provider came along, it had to be added to each app one by
one — doubly dull. So I came up with one hub for all of them.

## What's inside

- **Pluggable providers** — kept separate, so adding a new one is painless
- **Trust between apps** — not only people prove who they are, apps do too when they talk to each other: that keeps the perimeter secure
- **For any app** — plug in anything at all, not just apps from my ecosystem
